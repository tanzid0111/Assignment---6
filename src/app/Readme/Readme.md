1. FitLog — Workout Library & Tracker (project name )
2. Short description
FitLog is a dark-themed, modern, and no-nonsense gym companion web application designed to help fitness enthusiasts browse exercise routines, plan daily lifts, and track workouts efficiently.

3. Technologies Used

Framework: Next.js (React)
Language: TypeScript
Styling:Tailwind CSS
State & Data Management:React Hooks, LocalStorage
Deployment:Vercel

4. 5 Key Features

1. Comprehensive Exercise Library:Browse through a curated collection of major lifts and exercises categorized by target muscle groups.
2. Interactive Daily Planner:Easily select workouts and save up to 5 custom exercises directly into your active "Today's Plan".
3.Saved Workouts Collection: Bookmark favorite routines into a dedicated saved list for quick access during future training sessions.
4. Dynamic Sorting & Filtering: Sort your planned workouts by duration, calories burned, or rating to optimize your daily routine.
5. Real-time Analytics Counter: Track total exercises, estimated workout minutes, and overall calories burned with live-updating header badges.
